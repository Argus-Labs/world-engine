# data

Config/manifest-loading plugin for Cardinal. Loads versioned backend data
(definitions, manifests) into the world through a `ConfigManifest` component,
so game code can read authored data via the ECS rather than bespoke loaders.

## Regenerating the wire code

The `wire.gen.go` files (and the proto contract under `proto/`) are generated by `world sdk generate`. From the world-engine repo root:

```sh
world sdk generate ./pkg/plugin/data \
  --go-out ./pkg/plugin/data/gen \
  --proto-out ./pkg/plugin/data/proto
```

Requires Docker (the generator runs protoc/buf in a container). Rerun after changing any command/component/event struct in this plugin.
