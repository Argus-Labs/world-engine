## Prerequisites

Before you begin, make sure your local machine has the following installed:

- **Go**:

    World Engine games are written in [Go](https://go.dev). This guide requires a minimum Go version of **`v1.27.1`**. To check that Go is installed on your computer, run `go version`.

- **Docker**:

  The World Engine development server runs several local services inside containers. Follow the [official instructions](https://docs.docker.com/get-started/get-docker/) to install Docker.

<Tip>
  Alternatively, you can also use other Docker-compatible container runtimes. We recommend [OrbStack](https://orbstack.dev/) for macOS users and [Podman](https://podman.io/) for Linux users.
</Tip>

## Installing World CLI

The World CLI is the command-line tool for creating, managing, and deploying World Engine projects. It ships as a [Go tool](https://go.dev/doc/modules/managing-dependencies#tools) inside the World Engine module, so each project's CLI is the same version as its World Engine and there is nothing to install globally.

<Warning>
  The `install.world.dev` install scripts are deprecated. They install the last binary release (v2.5.1), which no longer receives updates.
</Warning>

## Creating a Project

Now you are ready to create a new World Engine project. The `setup` command will launch an interactive tool to help you configure your project:

```bash
go run github.com/argus-labs/world-engine/cli/cmd/world@latest setup my-game
```

When prompted, select the **Basic** template.

The new project's `go.mod` already declares the CLI as a tool. From inside the project, run it with `go tool world`. Start the local development server:

```bash
cd my-game
go tool world start
```

This command builds the game server and runs the World Engine stack. It will take some time during your first run to build the CLI and download the required container images.

<Tip>
  The rest of these docs write commands as `world <command>`. Add `alias world='go tool world'` to your shell profile to run them as written.
</Tip>

To add the CLI to an existing project, or to update it, run:

```bash
go get -tool github.com/argus-labs/world-engine/cli/cmd/world@latest
```

## Stopping the Server

Press <kbd>Ctrl+C</kbd> to stop the server, or run `world stop` from another terminal.

To reset the world state, run `world purge`. This removes all game data and restores the world to a clean state, which is useful when you want to start fresh during development.
