## Initializing the Client

Create a client with a configuration object that specifies the auth URL and region configs.

Locally, shards authenticate players the way the project's `world.toml` `[auth]` section says (see [Project Structure](/project-structure#player-authentication)). With `mode = "argus"`, sign in as you would in production. With `mode = "dev"`, use dev auth to skip sign-in, as below.

<Tabs>
  <Tab title="Unity C#">
    ```csharp
    using WorldEngine.SDK;
    using WorldEngine.SDK.Client;

    var config = new WorldClientConfig
    {
        AuthUrl = "http://localhost:3000",
        // The game: sign-in and every shard use this organization and project.
        Organization = "my-org",
        Project = "my-game",
        AuthClientOverride = new DevAuth("dev-player-1"),
        Regions = new Dictionary<string, RegionConfig>
        {
            ["us-west1"] = new RegionConfig
            {
                GatewayUrl = "http://localhost:8080",
                DisplayName = "US West"
            }
        }
    };

    var client = new WorldClient(config);
    ```

## Authentication

`client.AuthStatus` says what the game can do: `SignedOut`, `NeedsRefresh` (a saved login needs a fresh game token), or `Ready`. `client.Player` says who is playing. `client.AuthChanged` fires on Unity's main thread whenever either changes. Cardinal identifies the player by the stable player ID in the game token.

<Tabs>
  <Tab title="Unity C#">
    ```csharp
    client.AuthChanged += Render;
    Render();
    if (client.AuthStatus == AuthStatus.NeedsRefresh)
        await client.RefreshAuthAsync();

    // On a sign-in button:
    var result = await client.SignInAsync(); // or SignInAsGuestAsync()
    if (result != AuthResult.Success)
        Debug.LogWarning($"Sign-in did not finish: {result}");

    void Render()
    {
        if (client.Player is PlayerState.Registered player)
            Debug.Log($"Signed in as {player.Email} (Player: {player.Id})");
    }
    ```

## Connecting to a Shard

A shard is a single instance of your game world running on the server. The shard client is your connection to that instance, allowing you to send commands and subscribe to events.

To connect, specify the shard's region and ID and call connect to get a shard client. The organization and project come from the client config.

<Tabs>
  <Tab title="Unity C#">
    ```csharp
    var addr = new ShardAddress
    {
        Region = "us-west1",
        ShardId = "game-shard"
    };

    var shard = await client.ConnectShardAsync(addr);
    ```
