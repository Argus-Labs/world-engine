World Forge has been retired. The Forge workflow previously documented here — including
`world deploy`, `world promote`, `world status`, and `world logs` — is no longer available.

Deploy gateways and shards through your infrastructure workflow. Configure the same region ID
on the gateway, shards, and clients. The GCP deployment uses `us-west1`. See
[Deployment](/forge/deployment) for details.
